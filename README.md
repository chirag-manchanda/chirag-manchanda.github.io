# chirag-manchanda.github.io

Personal academic website of **Chirag Manchanda**.

Live site: https://chirag-manchanda.github.io/

## Structure

This is a static website hosted with GitHub Pages.

- `index.html` — main website
- `publications/index.html` — publications page
- `cv/index.html` — CV page
- `files/Chirag_Manchanda_CV.pdf` — current CV
- `images/` — site images and favicon
- `.nojekyll` — tells GitHub Pages to serve the files directly
